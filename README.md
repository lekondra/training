# Тренировки для колена

Одна страница `index.html` без зависимостей (шрифты подгружаются с Google Fonts). Открывается двойным щелчком или через GitHub Pages.

- Две тренировки в неделю, дни недели выбираются.
- Упражнения реабилитолога уже в программе, остальные добавляются из библиотеки.
- Подходы, повторения и вес редактируются на странице.
- Дневник: кнопка «Записать в дневник» сохраняет тренировку с датой, весами, самой сильной болью и заметкой. Рядом с упражнением показан вес с прошлого раза, а в фильтре дневника видна динамика веса по выбранному упражнению.

## Где хранятся данные

Всё, что вы меняете (программа, дневник, отметки), хранится в браузере (localStorage) на конкретном устройстве. Чтобы не потерять:

- на странице, раздел «Резервная копия»: скачать файл или скопировать текст копии, потом восстановить;
- перед сбросом или восстановлением прежняя версия сохраняется, её можно вернуть;
- сама страница защищена историей коммитов этого репозитория.

Программа не заменяет рекомендации врача: боль не выше 3 из 10, без отёка колена.
