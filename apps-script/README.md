# Синхронизация дневника с Google Таблицей

Один раз настраивается примерно за 5 минут. Таблица нужна, чтобы записи с телефона и компьютера объединялись, и чтобы дневник было удобно смотреть как таблицу.

1. Создайте новую Google Таблицу, например «Дневник тренировок».
2. Меню **Расширения → Apps Script**. Удалите содержимое редактора и вставьте весь код из файла `Code.gs`.
3. В первой строке замените `ЗАМЕНИТЕ_НА_СВОЙ_ПАРОЛЬ` на свой пароль (любая строка, её знаете только вы). Сохраните проект.
4. **Развернуть → Новое развертывание → тип «Веб-приложение»**.
   - Выполнять от имени: **я**.
   - У кого есть доступ: **все**. Без пароля из шага 3 скрипт ничего не отдаёт.
5. Разрешите доступ к таблице (Google попросит подтверждение при первом запуске) и скопируйте адрес веб-приложения, он оканчивается на `/exec`.
6. Откройте страницу **с GitHub Pages** (из просмотра в Claude внешние запросы заблокированы). Раздел «Синхронизация с Google Таблицей»: вставьте адрес и пароль, нажмите «Сохранить и синхронизировать».

Дальше записи отправляются сами после каждого «Записать в дневник» и при открытии страницы.

## Что появится в таблице

- Лист **Дневник**: строка на каждое упражнение (дата, день, упражнение, подходы, повторения, вес, боль, заметка).
- Лист **_data**: служебный, не правьте его вручную.

## Если поменяли код скрипта

После правки кода нужно снова нажать **Развернуть → Управление развертываниями → ✏ → Версия: новая → Развернуть**. Адрес останется прежним.
